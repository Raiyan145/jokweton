# GUESSX

Premium animated virtual prediction/guessing game UI.

Games:
- Color Rush: Yellow / Red / Blue
- Number 1–10
- Black / White
- Virtual coins
- Animated reveal
- Win particle burst
- Global Top 10 leaderboard UI

This build is a frontend prototype. It uses fictional coins only and does not process real money.

For multiplayer accounts/leaderboard, connect the UI to Supabase Auth + Postgres.
